# Estrera_LabAct_Music
This is a project that uses a API Key.

Its a search website that uses the Pixabay API to search for photos and videos.

# Features:
- Search Pixabay for any term
- Option between photos and videos
- Results displayed on the same page
- Loading indicator while requests are running
- Error message when a request fails

# Prerequisites
You'll need a Pixabay API key to run this project.

Make a local config.js file and add your API key:

const API_KEY = "YOUR_PIXABAY_API_KEY";

A config.sample.js file is included as a template for creating your own config.js.

# Running Locally
Clone the repository:
git clone git@github.com:YOUR-USERNAME/YOUR-REPOSITORY.git

Open the project folder.

Create config.js by copying config.sample.js.

Replace the placeholder API key with your real Pixabay API key.

Open index.html in your browser.

The website should now be ready to use. Enjoy!
